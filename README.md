# Claude From Zero — Demo

**用于演示的项目。**

这是 [Claude From Zero](https://claude-from-zero.dev) 教程站的演示版本，基于 Nuxt 4 + nuxt-content + Nuxt UI 构建，展示中文技术文档站的完整工程实践。

---

## 技术栈

- **Nuxt 4** — Vue 全栈框架
- **nuxt-content** — Markdown 内容管理
- **Nuxt UI 3** — 组件库
- **Tailwind CSS v4** — 样式系统
- **GitHub Pages** — 静态托管

## 本地开发

```bash
cd packages/website
pnpm install
pnpm dev
```

## 构建

```bash
cd packages/website
pnpm build
```

构建产物位于 `.output/public`，可直接部署到任意静态托管服务。
