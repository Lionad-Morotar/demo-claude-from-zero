# Review: 7.3-安全与权限控制.md

## 事实准确性

### [1][2] Permission Mode 和 `--permission-mode` — 基本正确
- **核实**: 四种主要模式（default/acceptEdits/plan/bypassPermissions）描述与官方一致。
- **建议**: 补充 `auto` 和 `dontAsk` 两个额外模式，使描述更完整。

### [3] `/plan` 和 `/acceptEdits` — 需要修改
- **核实**: `/plan` **属实**；`/acceptEdits` **不属实**。
- **问题**: 原文"/acceptEdits 切回快速模式"是技术错误。权限模式切换官方推荐 `Shift+Tab`（循环切换）或启动时通过 `--permission-mode` 参数指定。
- **建议**: 删除 `/acceptEdits` 命令描述，改为"通过 `Shift+Tab` 循环切换至 `acceptEdits` 模式"。

### [4] settings.json `permissions.allow/deny` 语法 — 建议添加免责声明
- **问题**: 官方 settings 文档结构复杂，未能直接提取精确 schema。`Bash(pnpm test:*)` 括号和 glob 语法虽与官方 matcher 规则有类似先例，但未完全确认。
- **建议**: 添加"示例仅供参考"的免责声明，或进一步验证精确语法。

### [5][6] Hooks JSON 格式 + `$TOOL_INPUT` — 需要修改
- **核实**: `"type": "command"` 属实；但官方 Hooks 文档明确命令钩子**通过 stdin 接收 JSON**，而非环境变量。`$TOOL_INPUT` **未在官方文档中出现**。
- **建议**: **将所有 `$TOOL_INPUT` 替换为 stdin 读取方式**，如 `jq -r '.tool_input.command' < /dev/stdin`，并补充说明官方 Hooks 通过 stdin 传递 JSON。

### [7] `claude --check-hooks` — 需要修改
- **核实**: CLI reference 和官方文档中**未找到**此命令。
- **建议**: 删除 `claude --check-hooks` 建议，替换为 `/doctor` 命令或手动检查 settings 文件语法。

### [8] `docs.anthropic.com/claude/docs/claude-code` 链接 — 需要修改
- **问题**: 该 URL 格式与当前官方文档域名 `code.claude.com/docs/en/...` 不一致。
- **建议**: 替换为当前有效链接。

### [9] Google SRE Book Security 链接 — 需要修改
- **问题**: 链接指向 `practical-alerting` 章节，而非 Security 相关章节。
- **建议**: 替换为 `https://google.github.io/building-secure-and-reliable-systems/` 或 `https://sre.google/books/`。

### [10] Charity Majors 链接 — 需要修改
- **问题**: 链接指向个人博客首页，而非"Operational Maturity Levels"具体文章。
- **建议**: 替换为具体资源，如 O'Reilly《Observability Engineering》第 21 章链接。

## 逻辑/覆盖度

### [F] Hook 命令逻辑 bug — 需要修改
- **问题**: 第 177 行 Hook 命令的 `&&` 逻辑 bug——该命令只会在"git 命令 + 大文件"组合时触发，而非"有大文件时阻止提交"。
- **建议**: 修正逻辑为正确的文件大小检测和阻止提交逻辑。

### [G] Hook 命令 `$(pwd)` 边界条件 bug — 需要修改
- **问题**: 第 409 行 Hook 命令的 `$(pwd)` 在项目路径位于 home 目录下时会误匹配。
- **建议**: 使用更精确的路径匹配方式。

### [C] "匿名事故案例" — 建议标注
- **建议**: 明确标注为"假设性示例"或提供可验证来源。

## 总体评价

本章 Permission Mode 的核心概念正确，但存在三个技术性错误（`/acceptEdits` 命令不存在、`$TOOL_INPUT` 环境变量错误、`claude --check-hooks` 命令不存在）和一个 Hook 逻辑 bug，这些错误会直接误导读者的操作。建议优先修正这四项。
